# nimbus-data-science-simulation
A trial-conversion cohort analysis for a simulated B2B SaaS product; defined activation and conversion metrics, audited data quality, identified onboarding-related retention patterns, and delivered a stakeholder-ready recommendation with limitations and next-step experiment design.

This repository simulates my first weeks as a Junior Data Scientist at Nimbus, a B2B productivity SaaS company.

Structure
docs/ - company, product, and data documentation

data/ - mock warehouse tables (CSV format)

sql/ - exploratory and baseline analysis queries

analysis/ - working notes, memos, and findings

slack/ - simulated stakeholder messages

Day 1 deliverable
Complete analysis/day1_notes.md, then commit and push it to GitHub.

Day 2 deliverable
Run the SQL queries against the CSV data, document assumptions, and prepare a baseline conversion report.
